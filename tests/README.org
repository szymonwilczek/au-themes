Every theme is checked by the modules in this directory before it is
released.  Back to the [[file:../README.org][README]].

* Running the tests

Run all modules on all themes from the repository root:

#+begin_src sh
  emacs -Q --batch -L . -l tests/run-all-tests.el
#+end_src

Set =AU_TEST_THEMES= to check only some themes, for example
=AU_TEST_THEMES=au-salina-night=. The run fails if any theme
fails any module.

The tests look for modus-themes in your =elpa= directory. Without it
installed, put it in a separate directory first:

#+begin_src sh
  export EMACS_ELPA_DIR=/tmp/au-elpa
  emacs -Q --batch -l tests/install-deps.el
  emacs -Q --batch -L . -l tests/run-all-tests.el
#+end_src

* How a run works

1. [[file:run-all-tests.el][run-all-tests.el]] finds every =au-*-theme.el= in the repository,
   or takes the themes named in =AU_TEST_THEMES=.
2. For each theme it reads the palette through
   [[file:test-palette-extractor.el][test-palette-extractor.el]], which resolves every named colour to a
   hex value and holds the colour maths the modules share: sRGB,
   CIELAB, CIEDE2000, Oklab and Oklch, and APCA.
3. It then runs each module listed in =rf-test-modules=.  A module is
   a file =test-<name>.el= with a function =test-<name>-run=.  It
   measures the palette roles with its model, prints a =[PASS]= or
   =[FAIL]= line for each check, and returns a pass, a fail, or a skip
   when it does not apply to the theme (a module for one family only,
   for example).  Some checks only print a =NOTE= and never fail.
4. At the end it prints a summary of passed, failed and skipped runs.
   The run exits with status 1 if any module fails for any theme.

Some gates, such as the all-pairs separation of syntax roles, comment
recession and colour difference at glyph size, hold only for the
families in =au-test-strict-families= (in
[[file:test-palette-extractor.el][test-palette-extractor.el]]).  Families released before these gates
join the list once they have been retuned.

the result with a limit. Most of the limits are ours: we chose them
for these palettes, and they are not clinical thresholds. The table
says which parts come from a source and which are our own choice.
